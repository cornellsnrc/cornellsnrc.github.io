# Permanent website images

This folder contains images used outside the Gallery:

- logos and banner artwork live directly in `assets/images/branding/`;
- the overlapping home-page collage lives in `assets/images/branding/home/`;
- officer portraits belong in `assets/images/officers/` instead; and
- event albums and their originals must be uploaded through private `snrc-photo-archive` Releases.

When changing a home-page collage image, upload its permanent copy to `assets/images/branding/home/`, then enter only its filename in `_data/home.yml`. Do not reference an image inside a Gallery album because public albums may later be removed while permanent page artwork must remain available.
