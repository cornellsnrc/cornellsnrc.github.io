# Gallery photos

Create one folder per event, then upload photos into it. Example:

`assets/images/gallery/2026-fall-picnic/picnic-01.jpg`

Each folder becomes its own album on the main Gallery page. Every JPG, JPEG, PNG, WebP, or AVIF inside that folder appears automatically in the album after the commit deploys. The folder name becomes the album title, and each filename becomes the image description, so use descriptive names such as `botanic-gardens-group-photo.jpg`.

Do not upload a photo that should remain private or that the organization does not have permission to publish.
