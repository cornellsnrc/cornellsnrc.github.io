# Gallery photos

Create one folder per event, then upload photos into it. Example:

`assets/images/gallery/2026-fall-picnic/picnic-01.jpg`

Every JPG, JPEG, PNG, WebP, or AVIF file placed anywhere below this folder appears automatically on the Gallery page after the commit deploys. The filename becomes the image description, so use descriptive names such as `botanic-gardens-group-photo.jpg`.

Do not upload a photo that should remain private or that the organization does not have permission to publish.
